# PrepPilot — Project Overview

PrepPilot is an offline-first AI-assisted study tracking application.

Its main purpose is to let students organize their syllabus and understand their actual completion progress.

Core hierarchy:

**Subject → Chapter → Topic**

Android is the primary platform. A web application exists for demonstration and portfolio presentation.

The core tracker works offline.

AI is a secondary online feature powered by Google Gemini.

## Core Workflow

Add syllabus → Track topics → Study → Record time → View progress → Optionally use AI

## Core Principle

**Tracker First, AI Second.**

PrepPilot is for individual self-improvement and does not include social networking.

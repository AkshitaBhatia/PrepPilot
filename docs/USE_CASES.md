# PrepPilot — Use Cases

## UC-01 Register/Login

Student authenticates using email/password, Google or phone/OTP.

## UC-02 Create Subject

Student creates a new subject.

## UC-03 Create Chapter

Student adds a chapter to a subject.

## UC-04 Create Topic

Student adds a topic to a chapter.

## UC-05 Complete Topic

Student checks/unchecks a topic and progress updates.

## UC-06 View Progress

Student views chapter, subject and overall progress.

## UC-07 Start Timer

Student starts Stopwatch, Pomodoro or Custom timer.

## UC-08 View History

Student views recorded study sessions.

## UC-09 Import Template

Student previews and imports a prebuilt syllabus.

## UC-10 Customize Template

Student edits imported syllabus content.

## UC-11 Ask AI

Student requests Gemini assistance.

## UC-12 Create Reminder

Student schedules a reminder/alarm.

## UC-13 Focus Mode

Student starts a supported Android focus session.

## UC-14 Synchronize

Local changes synchronize with Supabase.

## UC-15 Delete Account

Student deletes their account and associated data.

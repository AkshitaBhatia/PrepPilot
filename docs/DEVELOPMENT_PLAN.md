# PrepPilot — Development Plan

## Phase 0 — Foundation

Repository, Expo, TypeScript, Router, structure, docs, environment setup.

## Phase 1 — Design System

Theme, typography, spacing, buttons, cards, checkbox, progress, inputs, navigation.

## Phase 2 — Authentication

Email/password, Google, Phone OTP, sessions, protected routes.

## Phase 3 — Offline Tracker

Local database, subjects, chapters, topics, CRUD, completion.

## Phase 4 — Progress Engine

Chapter, subject and overall calculations, circular meters, progress bars, tests.

## Phase 5 — Timer

Stopwatch, Pomodoro, Custom, session recording.

## Phase 6 — Dashboard/History

Dashboard, history, total time, statistics.

## Phase 7 — Templates

10+ templates, Custom, preview, import, editing.

## Phase 8 — Synchronization

Supabase, queue, retry, conflict handling.

## Phase 9 — Notifications

Student alarms and repeating reminders.

## Phase 10 — AI

Gemini, explanations, Q&A, insights, requested planner.

## Phase 11 — Focus Mode

Permissions, supported restrictions, sessions, limitations.

## Phase 12 — Web

Demonstration UI using the same design language.

## Phase 13 — Testing/Polish

Functional, offline, sync, security, accessibility and visual testing.

## Phase 14 — Documentation

Printable report, DFD, workflows, architecture, testing, future scope and developer docs.

## September Goal

At least 75% of meaningful work complete by September. Core tracker work has priority over advanced AI.

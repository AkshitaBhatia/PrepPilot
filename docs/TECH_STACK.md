# PrepPilot — Technology Stack

## Mobile

- React Native
- Expo
- TypeScript
- Expo Router

## State

- Zustand or equivalent lightweight state manager

## Local Database

Select a reliable mobile database based on:

- Expo compatibility
- Android reliability
- Performance
- Offline-first support
- Synchronization support

## Backend

- Supabase
- PostgreSQL
- Supabase Auth

## AI

- Google Gemini API
- Secure server-side API layer

## Web

Modern browser-based stack compatible with the architecture.

## Documentation

- Markdown
- Mermaid

## Version Control

- Git
- GitHub

## Security

Secrets must use environment/server secret management.

Never commit Gemini keys, Supabase service-role keys or production credentials.

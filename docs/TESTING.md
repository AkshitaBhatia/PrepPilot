# PrepPilot — Testing Requirements

## Tracker

Test CRUD and completion for subjects, chapters and topics.

## Progress

Verify:

- 1/2 = 50%
- 2/2 = 100%
- Mixed chapter sizes
- Multiple subjects
- Overall calculation
- Empty chapters

## Offline

Test tracker, timers, sessions and history without internet, then synchronize after reconnecting.

## Authentication

Test:

- Email/password
- Google
- Phone/OTP
- Logout
- Session recovery
- Invalid credentials

## Timer

Test:

- Stopwatch
- Pomodoro
- Custom
- Pause/resume
- Stop
- Session persistence

## Templates

Test browsing, preview, import, editing and Custom.

## Notifications

Test one-time, repeating and disabled reminders.

## AI

Test online request, offline state, API failure, backend failure, response handling and prevention of automatic tracker modification.

## Security

Verify RLS, user isolation, no secrets in client code and secure account deletion.

## UI/UX

Verify spacing, typography, components, empty/loading/error states, accessibility and responsive web behavior.

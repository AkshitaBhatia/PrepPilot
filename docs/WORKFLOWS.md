# PrepPilot — Workflows

## 1. Registration/Login

Student → Select method → Authenticate → Session → Load data → Dashboard

## 2. Create Subject

Tracker → Add Subject → Enter name → Validate → Save locally → Show subject → Queue sync

## 3. Add Chapter

Subject → Add Chapter → Enter name → Save → Chapter appears

## 4. Add Topic

Chapter → Add Topic → Enter name → Save → Topic appears

## 5. Complete Topic

Check topic → Save state → Recalculate chapter → Recalculate subject → Recalculate overall → Update UI → Queue sync

## 6. Timer

Select Play → Timer opens for selected item → Choose mode → Start → Pause/resume → Stop → Save session → Update history/statistics

## 7. Template Import

Templates → Select → Preview → Confirm → Import → Edit if needed → Sync

## 8. AI

Student → AI → Request → Check connection → Secure backend → Gemini → Response → Display

AI never changes tracker data without confirmation.

## 9. Reminder

Notifications → Create → Set details → Save → Schedule → Notification

## 10. Focus Mode

Focus Mode → Configure → Permissions → Start → Supported restrictions → End

## 11. Offline

No internet → Local database → Tracker/timer/session use → Queue changes → Internet returns → Sync

## 12. Synchronization

Connectivity returns → Detect pending changes → Validate → Upload → Download → Resolve conflicts → Mark synchronized

## 13. Account Deletion

Settings → Delete account → Confirm → Delete cloud data → Clear local data → Authentication
